# Keep the project status up to date

`docs/project-status.md` is the running log of what has been built. Whenever a major feature is finished (a new page, module, or integration, not a small fix), add a row to its "Built" table with the date and a one-line note, and update "Not done yet" and "Before launch" if they changed. Do this in the same commit as the feature. Do not wait to be asked.
